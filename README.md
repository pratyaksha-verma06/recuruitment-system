# AI Recruitment System

An AI-based recruitment system developed as a **group project** to assist with candidate screening and evaluation using machine learning.

## Features

* Machine learning-based candidate evaluation
* Candidate screening and recruitment assistance
* Interactive web interface built with Streamlit
* Integrated ML workflow

## Tech Stack

* **Python**
* **Streamlit**
* **Scikit-learn**
* **Pandas**
* **NumPy**
* **Git & GitHub**
